# Attributs des unites de Total War: WARHAMMER III, par nom affiche.
#
# Source : db.pack du jeu de base — ATTENTION, c'est db.pack et non data.pack,
# qui ne contient aucune table.
#   - unit_attributes_to_groups_junctions_tables  (les 59 attributs reels) ;
#   - land_units_to_unit_abilites_junctions_tables (pour la seule regeneration) ;
#   - land_units_onscreen_name_* de local_en.pack, pour passer de la cle au nom.
# Extraction : ~\.claude\tools\tww\dump_db_rows.ps1, qui suit le SCHEMA de la table.
#   Ne PAS utiliser dump_db.ps1 : il extrait les chaines a plat et desynchronise
#   les colonnes des le premier champ numerique.
#
# Format :  Nom affiche <TAB> attribut,attribut,...
#
# DEUX PSEUDO-ATTRIBUTS ne viennent PAS de la table des attributs, mais de celle
# des capacites -- du point de vue d'une note de fiche, c'est la meme affirmation :
#   regeneration  wh_main_unit_passive_regeneration (72 unites) et sa variante
#                 nurglesque pestilent_regeneration (9). Soin continu.
#   the_hunger    les trois cles ...passive_the_hunger (79 unites au total). Le
#                 soin vampirique, qui rend des PV EN TUANT et non en continu.
# Les separer est indispensable : sans cela, quatre Varghulf decrits comme
# « regenerants » etaient signales a tort. Ils se soignent, mais pas ainsi.
# Methode validee sur les Trolls de Riviere, qui portent bien la Regeneration.
# La colonne healing_power de land_units ne discrimine rien : elle vaut 1 pour
# Volkmar comme pour un troll.
#
# QUAND PLUSIEURS UNITES PARTAGENT UN NOM (trois cles s'appellent « Dire Wolves »),
# la ligne porte l'UNION de leurs attributs. Le controle sous-signale donc plutot
# qu'il ne sur-signale — c'est le sens qu'on veut pour un outil informatif.
#
# LIMITE : le jeu de base seulement. Les unites ajoutees par un mod ont leurs
# tables dans leur propre pack et sont absentes d'ici ; verifier-attributs.ps1 les
# compte a part et ne dit rien d'elles.
#
# Regenerer apres un DLC : relancer les trois dumps ci-dessus, puis
# scratchpad\generer_attributs.ps1. Genere le 19/08/2026.
#
# 1456 unites portant au moins un attribut, sur 1550 noms distincts.
#
